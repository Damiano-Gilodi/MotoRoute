# MotoRoute

MotoRoute è un'applicazione web full stack per creare, gestire e condividere
itinerari motociclistici.

## Stack tecnologico

### Backend

- Java 21
- Spring Boot 4
- Spring Data JPA
- PostgreSQL
- Flyway
- Maven

### Frontend

- React
- JavaScript
- JSX
- Vite

### Infrastruttura

- Docker
- Docker Compose
- GitHub
- GitFlow

## Stato

Progetto in fase di sviluppo.
